Background

The TidyTuesday data for this week comes from Grambank, a database of grammatical features across the world’s languages. It includes information on 2,467 languages, 195 grammatical features, and the associated locations and language families.

A feature that interested me was the distinction between inclusive and exclusive forms of the first-person plural. Some languages distinguish between “we” including the person being addressed and “we” excluding that person. English of course uses the same pronoun in both cases.

Research question

How does the grammatical distinction between inclusive and exclusive forms of “we” vary across geographic regions and language families?

Analysis

Code
library(tidyverse)
library(sf)
library(rnaturalearth)
library(readr)

grambank_languages <- readr::read_csv('https://raw.githubusercontent.com/rfordatascience/tidytuesday/main/data/2026/2026-11-03/grambank_languages.csv')
grambank_parameters <- readr::read_csv('https://raw.githubusercontent.com/rfordatascience/tidytuesday/main/data/2026/2026-11-03/grambank_parameters.csv')
grambank_values <- readr::read_csv('https://raw.githubusercontent.com/rfordatascience/tidytuesday/main/data/2026/2026-11-03/grambank_values.csv')

# Variable for anguages with a distinction
clusivity <- grambank_values %>%
  filter(parameter_id == "GB028") %>%
  inner_join(grambank_languages, by = "language_id") %>%
  mutate(distinction = if_else(
    value == 1, "Distinction present", "No distinction"
  ))

# Percentage of languages with a distinction by region
region_rates <- clusivity %>%
  drop_na(macroarea) %>%
  group_by(macroarea) %>%
  summarize(
    n = n(),
    percent = 100 * mean(value == 1),
    .groups = "drop"
  )

# Ten largest language families
family_rates <- clusivity %>%
  drop_na(family_name) %>%
  group_by(family_name) %>%
  summarize(
    n = n(),
    percent = 100 * mean(value == 1),
    .groups = "drop"
  ) %>%
  slice_max(n, n = 10, with_ties = FALSE) %>%
  mutate(family_name = fct_reorder(family_name, percent))

# Spatial data
world <- ne_countries(scale = "small", returnclass = "sf") %>%
  filter(admin != "Antarctica")

language_map <- clusivity %>%
  drop_na(latitude, longitude) %>%
  st_as_sf(coords = c("longitude", "latitude"), crs = 4326)

theme_grammar <- theme_bw(base_size = 12) +
  theme(
    panel.grid.minor = element_blank(),
    plot.caption = element_text(
      size = 8,
      color = "gray50",
      lineheight = 1.1,
      margin = margin(t = 15)
    )
  )

We can first examine how the distinction varies across the geographic areas provided. This visualization compares the proportion of languages with inclusive/exclusive marking in each region.

Code
plot1 <- ggplot(region_rates, aes(
  x = percent,
  y = fct_reorder(macroarea, percent)
)) +
  geom_col(fill = "#0072B2", width = 0.65) +
  geom_text(
    aes(label = sprintf("%.1f%%", percent)),
    hjust = -0.15, size = 3.8
  ) +
  scale_x_continuous(
    limits = c(0, 100),
    breaks = seq(0, 100, 20),
    labels = scales::label_number(suffix = "%"),
    expand = expansion(mult = c(0, 0))
  ) +
  labs(
    title = "Inclusive/exclusive marking differs across regions",
    subtitle = "The distinction is most common in Papunesia and Australia, and least common in Africa",
    x = "Languages with distinction between types of marking (%)",
    y = NULL,
    caption = paste(
      "Percentages include only languages with a recorded value for GB028.",
      "Source: Grambank via TidyTuesday (11/3/2026). By: Arun Waran.",
      sep = "\n"
    )
  ) +
  theme_grammar +
  theme(
    plot.title = element_text(face = "bold"),
    plot.title.position = "plot",
    plot.caption.position = "plot",
    plot.caption = element_text(hjust = 0),
    panel.grid.major.y = element_blank(),
    axis.ticks.y = element_blank(),
    panel.border = element_blank()
  )

Code
plot3 <- ggplot() +
  geom_sf(
    data = world,
    fill = "gray96",
    color = "gray82",
    linewidth = 0.2
  ) +
  geom_sf(
    data = language_map,
    aes(color = distinction),
    size = 0.9,
    alpha = 0.8
  ) +
  scale_color_manual(
    values = c(
      "Distinction present" = "#0072B2",
      "No distinction" = "#D55E00"
    ),
    name = NULL
  ) +
  coord_sf(
    crs = st_crs(8857),
    datum = NA,
    expand = FALSE
  ) +
  guides(
    color = guide_legend(
      override.aes = list(size = 3.5, alpha = 1)
    )
  ) +
  labs(

    subtitle = "Geographic distribution of languages with marking classifications",

      "Source: Grambank via TidyTuesday (11/3/2026). By: Arun Waran.",
      sep = "\n"
    )
  ) +
  theme_void(base_size = 12) +
  theme(
    plot.title = element_text(face = "bold", size = 16),
    plot.subtitle = element_text(size = 11, color = "gray35"),
    plot.title.position = "plot",
    plot.caption.position = "plot",
    plot.caption = element_text(
      size = 8,
      color = "gray50",
      hjust = 0,
      lineheight = 1.1,
      margin = margin(t = 12)

    legend.text = element_text(size = 10),
    legend.key = element_blank(),

plot3

Via the map, we see that languages with inclusive/exclusive marking are especially common in Papunesia (which includes the Philippines and New Guinea), as well as Australia. Many languages in Africa and Eurasia do not have the distinction, and the Americas show a more mixed distribution.

Final takeaways

Inclusive/exclusive marking varies considerably across regions. It is in 78.5% of the documented languages in Papunesia and 74.5% in Australia, but only 28.5% in Africa.

Language families also differ substantially. 93.9% of Austronesian languages have the distinction, compared with only 9.1% of Indo-European languages.

The geographic distribution shows considerable variation within regions. Both categories appear throughout the world, but especially in the Americas.
